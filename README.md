# Suno Prompt Studio — موقع مستقل

مكتبتك الذكية لصناعة الموسيقى والتعليق الصوتي: 35 برومبت Suno أصلي في 7 أقسام، مع بحث ونسخ وتخصيص ومفضلة وبرومبتاتي.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كامل (التصميم + البرومبتات + الوظائف) |
| `manifest.webmanifest` | إعدادات الإضافة للشاشة الرئيسية |
| `apple-touch-icon.png` | أيقونة الآيفون |
| `icon-192.png` / `icon-512.png` | أيقونات أندرويد والمتصفحات |
| `.nojekyll` | يخلي GitHub Pages ينشر الملفات كما هي |

ما يحتاج بناء (build) ولا مكتبات، ولا اشتراكات. أي استضافة ملفات ثابتة تشغّله.

## النشر على GitHub Pages (مجاني)

1. سجّل دخول في github.com.
2. اضغط **+** فوق ← **New repository**، سمّه مثلًا `suno-prompt-studio`، وخلّه **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، واسحب كل الملفات اللي داخل المجلد (مو المجلد نفسه)، ثم **Commit changes**.
   - ملاحظة: ملف `.nojekyll` مخفي في بعض الأجهزة. إذا ما ظهر لك، الموقع يشتغل بدونه عادي.
4. روح **Settings** ← **Pages**.
5. في **Source** اختر **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، ثم **Save**.
6. انتظر دقيقة أو دقيقتين، وبيطلع لك الرابط بهالشكل:
   `https://اسم-حسابك.github.io/suno-prompt-studio/`

## النشر على Vercel (مجاني)

1. ارفع الملفات على GitHub مثل الخطوات 1 إلى 3 فوق.
2. سجّل في vercel.com بحساب GitHub.
3. **Add New** ← **Project** ← اختر المستودع ← **Deploy** (بدون أي إعدادات إضافية).
4. بيعطيك رابط مثل: `https://suno-prompt-studio.vercel.app`

## إضافته للشاشة الرئيسية في الآيفون

1. افتح الرابط في **Safari**.
2. اضغط زر المشاركة (المربع اللي فيه سهم لفوق).
3. اختر **إضافة إلى الشاشة الرئيسية** ← **إضافة**.

بيظهر بأيقونة الميكروفون الذهبي، وينفتح بملء الشاشة بدون شريط Safari.

## ملاحظات

- **الحفظ:** المفضلة وبرومبتاتي محفوظة في LocalStorage، يعني داخل المتصفح اللي تستخدمه فقط. ما تنتقل بين الجوال والكمبيوتر، ومسح بيانات Safari يمسحها.
- **النسخ:** يحتاج رابط HTTPS، و GitHub Pages و Vercel يعطونك HTTPS تلقائيًا. إذا منع المتصفح النسخ التلقائي، تطلع نافذة فيها النص محدد للنسخ اليدوي.
- **الإنترنت:** الخطوط تنحمّل من Google Fonts. بدون إنترنت التطبيق يشتغل بخط النظام البديل.
- **التعديل:** البرومبتات موجودة داخل `index.html` في المصفوفة `var P=[`.
